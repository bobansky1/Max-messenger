# MAX Messenger MVP

Простой веб-мессенджер для MAX с использованием GREEN-API и React.

## 🚀 Возможности

- 🔐 Авторизация через GREEN-API (idInstance и apiTokenInstance)
- 💬 Отправка текстовых сообщений
- 📨 Получение входящих сообщений в реальном времени
- 📱 Адаптивный дизайн, похожий на MAX Web
- ⚡ Быстрый и простой интерфейс

## 📋 Требования

- Node.js версии 16 или выше
- npm или yarn
- Учетная запись GREEN-API (можно зарегистрироваться на https://green-api.com/max/)

## 🛠️ Локальный запуск

## 📖 Как использовать

### Шаг 1: Получение учетных данных GREEN-API

1. Зарегистрируйтесь на https://green-api.com/max/
2. Создайте новый инстанс
3. Получите `idInstance` и `apiTokenInstance`
4. Убедитесь, что инстанс авторизован и активен

### Шаг 2: Авторизация в приложении

1. Откройте приложение в браузере
2. Введите ваш `idInstance`
3. Введите ваш `apiTokenInstance`
4. Нажмите кнопку "Войти"

### Шаг 3: Создание чата

1. После успешной авторизации введите номер телефона получателя
2. Формат номера: `+79001234567` или `89001234567`
3. Нажмите "Начать чат"

### Шаг 4: Отправка и получение сообщений

1. Введите текстовое сообщение в поле ввода
2. Нажмите кнопку отправки (➤) или Enter
3. Сообщение будет отправлено получателю через MAX
4. Входящие сообщения будут автоматически появляться в чате

## 🌐 API интеграция

Приложение использует следующие методы GREEN-API:

### Отправка сообщений
```
POST https://api.green-api.com/waInstance{idInstance}/sendMessage/{apiTokenInstance}
```

### Получение уведомлений
```
GET https://api.green-api.com/waInstance{idInstance}/receiveNotification/{apiTokenInstance}
```

### Удаление уведомлений
```
DELETE https://api.green-api.com/waInstance{idInstance}/deleteNotification/{apiTokenInstance}/{receiptId}
```

### Проверка состояния
```
GET https://api.green-api.com/waInstance{idInstance}/getStateInstance/{apiTokenInstance}
```

## 📱 Особенности реализации

- **Polling** для получения новых сообщений каждые 2 секунды
- Автоматическая прокрутка к последним сообщениям
- Форматирование номеров телефонов в формат chatId
- Проверка валидности учетных данных при авторизации
- Обработка ошибок и loading состояний
- Адаптивный дизайн для мобильных устройств

## 🐛 Известные ограничения

- Поддержка только текстовых сообщений
- Работа с одним чатом за раз
- История сообщений не сохраняется при перезагрузке
- Требуется активный и авторизованный инстанс GREEN-API
